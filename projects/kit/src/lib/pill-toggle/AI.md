# AI notes: Pill toggle

- Put it on the left of the figure it switches; the figure has no label of its own then.
- Give each option an `ariaLabel` that says what it reads and what a tap does.
- Labels are whole words; an app's single named exception (substance-tracker's "qty") must be in its design.
- Never use it for navigation or for an action: it only switches what is shown.
